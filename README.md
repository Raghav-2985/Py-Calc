# Py-Calc

### `Status Of Project: Completed`

#### Py-Calc (Python Calculator) is a ligthweight calculator that supports 12 different operation and it compatible with almost all python installed devices.

# Tech Stack
- Python 3.14
- Python built-in `math` library

# Prerequisites
### Py-Calc is built on built-in libraries and it only requires you to install `python 3.14` or later.

# Getting Started

- Clone the repostiory using the below command in git bash:
  
  ```bash
  git clone https://github.com/Raghav-2985/Py-Calc.git
  ```

- Change the directory and run the program using python or open it using an code editor or ide (here is an example with visual studio code):
   
   ```bash
   cd Py-Calc/
   code . # To open the program in vs code
   python3 main.py # To run the main.py file
   ```

# Commands and Usage Examples

### Commands:

#### Py-Calc uses a number based input system where the program requires number from 1 to 12 (Read the table below to find the number and the assigned operation):

| Number | Operation Assigned |
| ------ | ------------------ |
|  1     | Addition           |
|  2     | Subtraction        |
|  3     | Multiplication     |
|  5     | Division           |
|  6     | Floor              |
|  7     | Modulo Division    |
|  8     | Square (Single number is allowed)     |
|  8     | Cube (Single number is allowed)       |
|  9     | Square Root (Single number input is allowed)      |
|  10    | Cube Root (Single number input is allowed)        |
|  11    | Abs (Single number input is allowed)       |
|  12    | Exponential terms (2 number inputs are allowed: 1. The number itself 2. Its power)    |
